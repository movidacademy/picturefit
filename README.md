# PictureFit

PictureFit is a free, self-contained browser tool for preparing images for upload forms.

- Resize JPG, PNG, or WebP images to a maximum file size and optional dimensions.
- Create a fresh PNG copy from the visible pixels without carrying over source file metadata such as EXIF or GPS.
- Process multiple images and download results individually or together in a ZIP file.
- Work entirely in the browser; images are not uploaded to a server.

Open `index.html` in a modern browser to use the tool. No installation or build step is required.

A clean visual copy removes source file metadata, but it does not remove information deliberately hidden in pixel values. Color appearance can change slightly for wide-gamut or HDR images.
